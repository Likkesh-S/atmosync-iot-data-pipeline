# AtmoSync

AtmoSync is an environmental telemetry and data analytics project.

## Objective

Analyze environmental telemetry data, calculate hourly metrics, and prepare the results for dashboards and reporting.

## Technologies

- Python
- Pandas
- SQL
- Snowflake
- Apache Superset
- GitHub

## Project Workflow

1. Collect telemetry data
2. Clean and validate the data
3. Calculate hourly metrics
4. Store and query data using SQL
5. Create dashboard visualizations
6. Document project results
