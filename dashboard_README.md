# AtmoSync Dashboard

This folder contains dashboard-related outputs for the AtmoSync project.

## Apache Superset

Connect Apache Superset to the AtmoSync telemetry or hourly metrics table.

Recommended charts:

1. Hourly average temperature
2. Peak and minimum temperature
3. Average humidity
4. Average pressure
5. Ping count by hour

## Dashboard Goal

The dashboard helps monitor environmental telemetry and identify changes in temperature, humidity, pressure, and data collection activity.
